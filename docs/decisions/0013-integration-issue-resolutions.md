# ADR-0013: Integration contracts resolved from the issue backlog

Date: 2026-09-21. Status: accepted for the design decisions listed below.

## Context and boundary

ADR-0001 retains the full feature scope and boundary compatibility; ADR-0002
and ADR-0005 require Rust project code and harnesses. This record resolves
specific choices in the issue bodies against the existing normative specs.
It does not report unbuilt components, unrun CI jobs, measurements, or release
acceptance as completed. References are to the repository specifications based
on Cilium v1.20.1 (`7d68cfb394`), not claims about a newer upstream release.

A decision issue is satisfied when its named choice and constraints are fixed.
The remaining implementation column stays part of the relevant milestone's
acceptance. A release must not infer feature availability from a closed design
issue. Full scope is retained; no feature is removed by this record.
