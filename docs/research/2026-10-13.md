## 2. Specs

- **Cilium 1.20** ([Isovalent post](https://isovalent.com/blog/post/cilium-1-20/)): datapath plugins,
  netkit, policy identity aggregation, ClusterNetworkPolicy support, stable MCS API. 1.20.1 was
  2026-08-18 (our reference pin is 1.20.1 `7d68cfb394`), so no reference change.
  Possible follow-up for #379/#336: ClusterNetworkPolicy and identity aggregation are not in our
  specs; not filed as an issue (no open issue depends on them; a design call for the owner).
- Cilium host firewall model (relevant to #379): the node is a reserved `host` endpoint, policies are
  clusterwide with `nodeSelector`, and an **audit mode** exists so policy can be observed before
  enforcement ([CNCF primer](https://www.cncf.io/blog/2025/09/03/securing-the-node-a-primer-on-ciliums-host-firewall/)).
  Audit mode is worth building into #379's design to avoid node lockout.
