# v0.2.0 — parser foundation prerelease

Adds the dependency-free flowsdn-scripttest parsing front end:
- Exact txtar archive reconstruction and shebang flag extraction.
- Quoted/unquoted fragments, conditions, status prefixes, sections,
  background syntax and source-line diagnostics.
- CRLF rejection following spec 17's recommendation for issue #210.

Validated on dev.g8.lo: 15 tests in debug and 15 in release; all 168 harvested
archives round-trip exactly, with 1,444 embedded files and 3,537 parsed commands.
Formatting, Clippy, both Linux musl architecture compile checks and cargo-deny
passed. Build output was cleaned afterward.

This is syntax coverage, not execution of the networking assertions. Runtime
commands, variable expansion, file materialization and subsystem adapters are
not implemented. There is no deployable agent, datapath or CNI yet.

Source-only prerelease; GitHub provides the tagged source archives.
See docs/implementation-status.md for validation details and the repaired
build-host /dev/null fault.
