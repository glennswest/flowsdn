# v0.5.0 — initialization and configuration sources

Adds named table initialization gates with explicit registration sealing,
idempotent source completion and cancellation-safe waits. Owners seal even
when no initialization sources are registered.

Adds flat YAML configuration, config-directory and environment adapters,
including projected ConfigMap symlinks, duplicate-key checks and deterministic
alias validation. Nested YAML remains outside the current loader contract.

Adds script variable expansion with quote preservation, undefined-empty
semantics and regex-safe substitutions. Command execution remains upcoming.

Source-only foundation prerelease. The full configuration catalogue,
reconciliation and networking agent/datapath remain unimplemented.

Validation: 71 unique tests passed in debug and release. Formatting, Clippy
with warnings denied, both Linux musl target checks and cargo-deny passed.
