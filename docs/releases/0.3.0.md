# v0.3.0 — table core and Rust inventory prerelease

Adds indexed immutable table snapshots, serialized writes, revisions, unique
and multikey indexes, and atomic batch publication. Ten table tests cover
concurrent access, retained snapshots, rollback on individual errors, and
comparison against an independent reference model.

Replaces the Python BPF inventory harvester with Rust. The new harvester
reproduces all 625 effective cases from 142 translation units, including their
features, entrypoints and milestones. Generated TOML also passes a round-trip
comparison. No Python source remains tracked.

Validated on Linux: 29 tests passed in both debug and release, formatting,
Clippy, compile checks for both Linux musl architectures, and cargo-deny.

Source-only foundation prerelease. Table watches, change streams and
reconciliation remain upcoming. There is no deployable networking agent,
datapath or CNI; harvested networking assertions are not executed yet.
