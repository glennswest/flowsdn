# v0.9.0 — map ABI and foreground script execution

Adds periodic reconciliation refresh with a force-write hint, bounded revision
scans and rate-spaced dispatch. Retry and cancellation retain refresh intent;
slow operations schedule subsequent passes from completion. Existing targets
retain a compatible default implementation. Batch operations remain forthcoming.

Introduces a dependency-free `no_std` map ABI subset: IPv4/IPv6 connection
tuples, address LPM keys, the frozen ipcache key and remote endpoint value.
Explicit byte codecs and layout assertions cover endian, offset and padding
contracts. Aya integration, map operations and BPF loading remain forthcoming.

Resolves 33 more configuration defaults from owning specifications with source
provenance. The catalogue now has 521 resolved defaults and 18 explicit gaps.
Conflicting declarations remain unresolved rather than selecting an arbitrary
value. Area-specific validators and help metadata remain incomplete.

Adds Linux foreground execution to the asynchronous script engine, including
output limits, explicit script environment, deadlines, cancellation and child
cleanup. The synchronous API rejects `exec`. A Rust helper tests real process
behavior, and workspace checks include feature-gated fixtures. Subprocesses
require trusted scripts; generic file-command confinement is not a process
sandbox. Background jobs and networking adapters remain forthcoming.

This is a source-only foundation prerelease. Networking execution remains
unimplemented.

Validation: 211 tests pass in debug and release with all features enabled.
Formatting, Clippy, x86-64 and arm64 Linux musl compile checks, and dependency
policy checks pass. Arm64 runtime and live networking remain unvalidated.
