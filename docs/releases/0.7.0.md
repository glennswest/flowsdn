# v0.7.0 — prune, snapshots, health and script files

Adds initialization-gated target pruning with coalesced requests, periodic
scheduling hints and cancellation replay. Resync remains required until a
successful prune; callers still own the background scheduling loop.

Adds runtime configuration snapshot encoding, decoding and atomic publication
with two history generations. Prior snapshots are size-bounded regular files;
unreadable or incompatible history produces nonfatal diagnostics. The complete
configuration catalogue remains forthcoming.

Adds module health reporters, scoped status rows, snapshot metric values and
readiness evaluation. Probe scheduling, HTTP serving and health-history files
are not implemented.

Adds confined script workspaces and generic file commands, including comparison,
copying, grep and replacement. File and expansion limits protect test execution;
subprocesses, background work, section retry and networking adapters remain
unimplemented. This is a source-only foundation prerelease.

Validation: 149 tests pass in both debug and release. Formatting, Clippy,
x86-64 and arm64 Linux musl compile checks, and dependency policy checks pass.
Arm64 runtime execution and networking compatibility are not yet validated.
