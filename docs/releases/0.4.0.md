# v0.4.0 — change streams and configuration foundation

Adds whole-table change streams with revision ordering, coalesced desired state,
explicit acknowledgements, retained deletion keys and bounded-lag resync.
Subscription and publication are synchronized; asynchronous waits preserve
changes when cancelled. Stream maintenance runs on writes and stream operations.

Adds a dependency-free configuration core: key normalization, compatibility
aliases, typed parsing, source precedence, repeated list flags and diagnostics.
The full key catalogue, file loaders, cross-key validation and runtime
persistence remain upcoming.

Source-only foundation prerelease. Initialization gates, reconciliation,
script execution and the networking agent/datapath are not implemented.
Validation results are recorded in docs/implementation-status.md.
