# v0.6.0 — reconciliation and script execution foundations

Adds a caller-driven reconciler with bounded rounds, separate revision-aware
status, cancellation replay and capped retry backoff. Full background scheduling,
prune/refresh and atomic desired-write status hooks remain upcoming.

Adds configuration cross-key validation and immutable restart comparisons.
Ignored settings do not activate features. Native-routing CIDR exceptions and
the complete configuration catalogue remain outside this slice.

Adds a script command/condition registry and executable echo, env, output
assertions and stop commands. Expected status and regex-safe expansion are
supported. Section retries, background work, filesystem/subprocess commands and
networking adapters are explicitly unsupported.

Adds dependency-aware workspace check selection, including transitive dependents
and patched dependencies. CI runner provisioning and remote caches remain future
work. This is a source-only foundation prerelease, without a networking agent.

Validation: 110 unique tests passed in debug and release. Formatting, Clippy
with warnings denied, both Linux musl target checks and cargo-deny passed.
