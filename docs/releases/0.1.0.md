# v0.1.0 — foundation prerelease

The first Rust implementation: a shared workspace and named startup fences.
There is no usable networking agent, datapath, CNI or deployable image yet.

- Rust 1.95.0 pinned; shared lints, lockfile and cargo-deny policy.
- Ordered startup barriers with cached results, cancellation-safe waiting,
  concurrent callers and watch-channel readiness.
- Linux xtask build/test/check/deny entry points.

Validated on Linux: formatting and Clippy; 7 tests in debug and 7 in
release; compile checks for x86_64 and aarch64 Linux musl; dependency advisories,
bans, licenses and sources. arm64 runtime and static linking are not yet tested.

Source-only prerelease; GitHub supplies tagged source archives. No deployable
binary artifacts are published. See docs/implementation-status.md for the
assessment of 287 open issues and the next implementation sequence.
