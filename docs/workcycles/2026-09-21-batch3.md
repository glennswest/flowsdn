and a fixture MTU mutation that unnecessarily reapplied the MAC and flushed

retains backing resources until safe cleanup is confirmed, with regressions for
transport disconnect, server error, malformed success and partial deletion.

Cleanup removed **20,074 files / 7.5 GiB** and fourteen task logs. No build
artifacts were copied between hosts or published as a release.
