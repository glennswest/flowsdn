# Connectivity evidence primitives

Bounded scenario-group flow storage rejects stale stream tokens and incomplete
negative-assertion evidence. Failed groups retain partial samples through the
explicit abort path. Transport readiness and cancellation remain caller duties.

CT comparison uses kernel map ID, tuple key and quiesced entry values. The ABI
has no creation timestamp. Hold the original map FD across observations;
matching bytes do not prove entry generation against identical reinsertion.

Lane placements distinguish trusted privileged checks, dedicated arm64 nightly
tests, five-node datapath churn and weekly simulated control-plane scale. These
are plans, not installed jobs or measured hardware. There is no e2e executable,
Hubble client, cluster provisioner or live traffic generator in this crate yet.
